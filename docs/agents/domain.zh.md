# 领域文档

[English](domain.md) | 中文

本仓库当前使用一个系统级领域上下文。

## 开始探索前

- 阅读根目录的 [`CONTEXT.md`](../../CONTEXT.md) 以了解通用语言。
- 在修改包或其组合前，阅读 [`docs/architecture.md`](../architecture.zh.md)。
- 阅读拥有目标领域决策的[活动 Agent Note](../../.agents/notes/README.zh.md)。
- 将[归档的 Agent Note](../../.agents/notes/archived/AGENTS.md)视为冻结历史，而不是当前依据。

## 词汇

在工单标题、验收标准、设计文档、测试和面向用户的标签中使用术语表中的术语。重新考虑 `CONTEXT.md` 明确标记为 `_Avoid_` 的同义词；在依赖缺失概念前，通过领域建模记录它。

只有在独立演进的包上下文需要单独的词汇表时，才引入 `CONTEXT-MAP.md`。
