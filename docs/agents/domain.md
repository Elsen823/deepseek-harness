This repository currently uses one system-wide domain context.

## Before exploring

- Read the root [`CONTEXT.md`](../../CONTEXT.md) for the ubiquitous language.
- Read [`docs/architecture.md`](../architecture.md) before changing packages or their composition.
- Read [active Agent Notes](../../.agents/notes/README.md) that own decisions in the target area.
- Treat [archived Agent Notes](../../.agents/notes/archived/AGENTS.md) as frozen history rather than current authority.

## Vocabulary

Use glossary terms in ticket titles, acceptance criteria, design documents, tests, and user-facing labels. Reconsider a synonym that `CONTEXT.md` explicitly marks with `_Avoid_`; record a genuine missing concept through domain modeling before depending on it.

Introduce `CONTEXT-MAP.md` only when independently evolving package contexts require separate glossaries.
